# Gear (rods and waders) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 5 rods (the player's catches of the rod's tiers sell for more; pick which owned rod to fish with) and 5 pairs of waders (best pair owned gives a shop discount; any owned pair is a look), drawn on the player's angler, with a Gear section in the panel.

**Architecture:** Gear definitions live in `data.ts` (`RODS`, `WADERS`, each with a free plain entry first). Rules live in `src/game/`: four state fields, `price`/`wadersDiscount` in `progress/economy.ts` used by every money purchase, buy/equip and the rod expected-value math in a new `progress/gear.ts`, and the rod bonus applied in `rollCatch` for the player only. Art keys looks by gear id in `art/sprites/figures.ts` and `art/icons.ts`; the scene builds player textures per gear combination on demand; the panel only shows and dispatches.

**Tech Stack:** TypeScript, Vitest, Phaser 4, HTML panel.

**Spec:** `docs/superpowers/specs/2026-10-18-gear-design.md`

## Global Constraints

- Rules stay in `src/game/`; the panel and scene never compute bonuses or discounts themselves. Every money price the panel shows comes from `price()` (or `helperCost`, which uses it).
- New `GameState` fields get defaults in `newGame()`; `SAVE_VERSION` stays 1; gear is not in `Carry`.
- Buy/equip functions return `boolean`.
- Starting numbers (all in `data.ts`, retuned only by Task 7's pacing, and only within what the "right pick" test allows):
  - Rods: `plainRod` (no tiers, 0, $0), `willowRod` common+uncommon +25% $500, `bambooCane` common +40% $3K, `fiberglassRod` uncommon +45% $15K, `graphiteRod` rare +40% $60K, `carbonSpey` legendary +40% $500K.
  - Waders: `plainWaders` 0% $0, `rubberWaders` 2% $300, `canvasWaders` 4% $4K, `neopreneWaders` 6% $40K, `breathableWaders` 8% $400K, `guideProWaders` 10% $3M.
- Copy: names "Plain Rod", "Willow Rod", "Bamboo Cane", "Fiberglass", "Graphite", "Carbon Spey"; "Plain Waders", "Rubber Waders", "Canvas Waders", "Neoprene Waders", "Breathable Waders", "Guide Pro Waders". Rod description "+25% on common and uncommon fish" / "+40% on rare fish"; plain rod "No bonus". Waders description "4% off the shop"; plain "No discount". Stamps "FISHING" / "WEARING" / "OWNED". Line under waders: "Discount now: 4%".
- The discount covers patterns, materials, places, helpers, rods and waders. Not fly tying, not license purchases.
- Helpers (`anglers[1..]`) never get a rod bonus and are drawn plain.
- Commits: one short imperative line, no trailers (user's rule).
- Every task ends with `npm test` and `npm run build` green (except where a step says pacing may be red until Task 7).

## Review Focus

- A save with a rod/waders id that no longer exists, or `rod` set to an unowned id → loads with that id dropped and plain equipped. Test in Task 1.
- Switching rods while a fish is already picked (`angler.pending`) or in the basket → its value doesn't change. Test in Task 4.
- Wearing an older pair after buying a better one → discount still from the best pair. Test in Task 3.
- Buying a pair: its own price uses the discount owned before buying it, and the money taken equals the shown price. Test in Task 2.
- New Season → plain gear only, equipped, regardless of what was owned. Test in Task 3.

### Task 4: Rod bonus on the player's catches, and the "right pick" test

**Files:**
- Modify: `src/game/fishing/catch.ts` (new `speciesWeight`; `rollCatch` gains a `rod` parameter)
- Modify: `src/game/fishing/sim.ts` (`pick`/`land` pass the rod)
- Modify: `src/game/progress/gear.ts` (new `rodGain`, `bestRod`)
- Test: `src/game/fishing/catch.test.ts`, `src/game/fishing/sim.test.ts`, `src/game/progress/gear.test.ts`, `src/game/progress/economy.test.ts`

**Interfaces:**
- Consumes: `equippedRod` (Task 3), `RODS`.
- Produces:
  - `speciesWeight(s: SpeciesDef, oddsBonus: number): number` — `s.weight × (1 + oddsBonus) ** TIERS.indexOf(s.tier)`, used by `rollCatch` (no behavior change).
  - `rollCatch(state, fly, rand, rod: RodDef = RODS[0])` — a fish's value gains `× (1 + rod.bonus)` when `rod.tiers` includes its tier. Junk and `size` untouched.
  - `sim.ts` passes `a.auto ? RODS[0] : equippedRod(state)`.
  - `rodGain(rod: RodDef, location: LocationId, maxDepth: number, oddsBonus: number, licensed: string[]): number` — Σ over `placeSpecies(location, licensed)` with `depth ≤ maxDepth` of `speciesWeight × baseValue × (rod covers tier ? rod.bonus : 0)`. Unnormalized; only for comparing rods.
  - `bestRod(state): string` — among owned rods, the one with the largest `rodGain` at `state.location` for the player's fly (the recipe's `flyStats`: `min(maxDepth, place maxDepth)` and `oddsBonus`); ties go to the earlier rod in `RODS`.

it('with every rod owned, each rod is the single best somewhere', () => {
