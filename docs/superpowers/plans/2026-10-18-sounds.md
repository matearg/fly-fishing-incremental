# Sounds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Synthesized chiptune sound effects for fishing, menu clicks and purchases, continuous water ambience per place, and a volume/mute row with a speaker icon in the title Settings.

**Architecture:** Pure, Node-tested modules in a new `src/audio/` hold the data and decisions: the settings model, each sound described as notes, per-place ambience parameters, and the cue functions that say which sounds fire between two frames. One thin Web Audio class (`SoundPlayer`) turns that data into sound and has no unit tests, like `src/scene/textures.ts` for art. `main.ts` owns the player and the setting. Scenes and the panel get a `play` hook, the same way they already get `getState`/`act`.

**Tech Stack:** TypeScript, Phaser 4.2.1 (its audio turned off), Web Audio API, Vite, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-18-sounds-design.md`

## Global Constraints

- `src/game/` gets no audio code. `pacing.test.ts` stays untouched and green.
- No sound files, no new dependencies. Every sound is generated with Web Audio.
- All art is drawn in code (pixel grids). New art goes through a user review stop on `/preview.html` before the build continues (CLAUDE.md).
- The volume setting lives under its own `localStorage` key (`flyfishing-sound`), outside `GameState` and the save. A missing, corrupt or out-of-range value falls back to the default (level 7 = 70%, unmuted) and never throws. Storage access never throws (private mode).
- The bar has 10 steps of 10%; the lowest step is 10%, and silence is mute.
- Only the player (`anglers[0]`) and the one visible helper (`anglers[1]`) make fishing sounds. The helper plays at `HELPER_GAIN` (quieter).
- Automatic actions are silent: no sound from `tick` itself (bench auto-tie, buyer auto-sell).
- All sound stops while the tab is hidden.
- Commits: short imperative one-line messages, no trailers or co-authors, never `--amend` (the user's rule).

## Review Focus

- **Before the first gesture:** loading the page must log no audio errors, and the first sound after a click must play. Chrome blocks an `AudioContext` until a gesture.
- **State swapped under the scene** (another tab's save adopted on tab return, Continue, New Season): no phantom splash and jingle from comparing the old state's reeling angler with the new state's idle one. Task 7 resets the fishing cues when the state object changes.
- **Hidden tab:** no ambience while hidden, and no burst of queued babble plips on return. Babble only schedules while the context is `running`.
- **Many helpers and `?speed=20`:** no flood. Only `anglers[1]` sounds, and cues are computed once per rendered frame (Task 3 tests a frame that crosses two thresholds).
- **A corrupt or blocked sound setting** never stops the game from loading (Task 1 tests).

### Task 3: Cue functions (which sounds fire)

**Files:**
- Create: `src/audio/cues.ts`
- Test: `src/audio/cues.test.ts`

**Interfaces:**
- Consumes: `SoundId`, `catchSound` (Task 2); `Track`, `BACK_MS`, `STRAIGHT_MS`, `CAST_MS` from `src/scene/fishing/choreo.ts`; `Angler`, `Phase`, `Pending` from `src/game/state.ts`.
- Produces:
  ```ts
  export interface CueFrame { phase: Phase; castMs: number; timerMs: number; pending: Pending | null }
  export function cueFrame(a: Angler | undefined, tr: Track): CueFrame | null // null when there's no angler
  export function anglerCues(prev: CueFrame | null, cur: CueFrame | null): SoundId[]
  export function panelCue(action: string, result: unknown): SoundId
  ```
- `anglerCues` rules, in this output order:
  1. `[]` if either frame is null.
  2. **Landed:** `prev.phase === 'reeling' && cur.phase !== 'reeling'` gives `'splashOut'`, then `catchSound(prev.pending)` (`'catch'` if pending is null).
  3. **Bite:** `prev.phase === 'waiting'` and `cur.phase` is `bite` or `reeling` gives `'bite'`.
  4. **Reel:** `cur.phase === 'reeling' && prev.phase !== 'reeling'` gives `'reel'`.
  5. **Cast** (only when `cur.phase === 'waiting'`): `since = cur.castMs - cur.timerMs`. `before` is `prev.castMs - prev.timerMs` if prev was waiting on the same cast (`prev.castMs === cur.castMs`), else `-1`. Each threshold `T` with `before < T <= since` fires, in order: `0` gives `'castBack'`, `BACK_MS + STRAIGHT_MS` gives `'castForward'`, and `CAST_MS` gives `'plip'`.
- `panelCue`: `hire`, `unlockPattern`, `unlockMaterial`, `unlockLocation`, `licenseUpgrade`, and `licenseSpecies` give `result ? 'buy' : 'nope'`. `sell` gives `result ? 'sell' : 'select'` (`sellAll` returns money earned). Anything else gives `'select'`.

- [ ] **Step 1: Write the failing tests** in `src/audio/cues.test.ts`, with a helper `f(phase, castMs, timerMs, pending = null)`:
  - Null prev or null cur gives `[]`.
  - New cast: `f('idle',0,0)` → `f('waiting',3000,3000)` gives `['castBack']`.
  - Forward: since 590 → 610 on the same cast gives `['castForward']`. Plip: since 990 → 1010 gives `['plip']`.
  - One frame that crosses two thresholds (since 500 → 1100) gives `['castForward','plip']`. Since 0 → 1500 gives the same (no second `castBack`).
  - No repeats: since 700 → 710 gives `[]`.
  - Bite: waiting → bite gives `['bite']`. bite → bite (the player waiting to click) gives `[]`.
  - Reel: bite → reeling gives `['reel']`. Helper same-frame: waiting → reeling gives `['bite','reel']`.
  - Landed: reeling with `dace` → idle gives `['splashOut','catch']`. Junk gives `['splashOut','junk']`. `brownTrout` gives `['splashOut','catchBig']`.
  - Helper lands and recasts in one frame: reeling with `dace` → `f('waiting',2000,1990)` gives `['splashOut','catch','castBack']`.
  - `panelCue('hire', true)` gives `'buy'`. `panelCue('hire', false)` gives `'nope'`. `panelCue('sell', 12)` gives `'sell'`. `panelCue('sell', 0)` gives `'select'`. `panelCue('travel', true)` gives `'select'`.

### Task 5: Sound player, wiring in main, sound review stop

**Files:**
- Create: `src/audio/player.ts`
- Modify: `src/main.ts`, `src/preview.ts`

**Interfaces:**
- Consumes: `SFX`, `AMBIENCE`, `TITLE_AMBIENCE`, `SoundId` (Task 2); `parseSound`, `soundStore`, `soundGain`, `serializeSound`, `SoundSettings` (Task 1).
- Produces:
  ```ts
  export class SoundPlayer {
    unlock(): void                          // creates/resumes the AudioContext; call from a user gesture; idempotent
    setVolume(gain: number): void           // master gain 0..1
    play(id: SoundId, scale = 1): void      // no-op until unlocked and while the context isn't 'running' (never queues)
    ambience(loc: LocationId | null, scale = 1): void // idempotent for the same args; a new place crossfades ~300 ms; null fades out
    pause(): void                           // ctx.suspend()
    resume(): void                          // ctx.resume(), only once unlocked
  }
  ```
  and, in `main.ts`, module-level `sound: SoundPlayer` and `let soundSettings: SoundSettings`, used by Tasks 6–8.
- Graph: notes → per-note envelope gain → master gain → destination. Noise comes from one 1 s white-noise buffer made once and looped through a lowpass `BiquadFilter`. Ambience: looping noise → lowpass(`cutoff`) → gain(`gain × scale`), with an LFO oscillator at `swellHz` through a gain of `swellDepth × base` into that gain's `.gain`. Babble: a 100 ms `setInterval` which, only while the context is `running`, plays a soft, randomly pitched plip with probability `babblePerSec × 0.1`. A private pitch multiplier on the note scheduler is fine.

- [ ] **Step 1: Implement** `src/audio/player.ts`.
- [ ] **Step 2: Wire `src/main.ts`:**

  - Create `const sound = new SoundPlayer()` and `let soundSettings = parseSound(soundStore.read())`, then call `sound.setVolume(soundGain(soundSettings))`.
  - Call `addEventListener(ev, () => sound.unlock(), { capture: true })` for `'pointerdown'` and `'keydown'`.
  - In the existing `visibilitychange` handler, call `sound.pause()` when hidden and `sound.resume()` on return.
  - In `frame()`, call `sound.ambience(session.state.location, session.mode === 'title' ? TITLE_AMBIENCE : 1)`.
